DATA PREPROCESSING – INTERVIEW QUESTIONS

1. What Is Data Preprocessing?

Data preprocessing is the process of cleaning, transforming, and preparing raw data before using it for analysis or machine learning. It improves data quality and makes the data suitable for further processing.

Common steps include:

* Handling missing values
* Removing duplicate records
* Handling outliers
* Encoding categorical data
* Scaling numerical features
* Correcting inconsistent data

2. Difference Between Data Wrangling and Data Preprocessing

Data Wrangling:

* The process of collecting, structuring, transforming, and organizing raw data into a usable format.
* Includes combining datasets, reshaping data, renaming columns, and changing data formats.
* Focuses on making data easier to work with.

Data Preprocessing:

* The process of preparing data for analysis or machine learning.
* Includes handling missing values, encoding categorical variables, scaling features, and handling outliers.
* Focuses on improving data quality and making data suitable for a specific task.

In short: Data wrangling focuses on organizing and transforming data, while data preprocessing focuses on preparing data for analysis or model building. The two processes can overlap.

3. How Do You Handle Missing Values?

Missing values can be handled using different methods depending on the dataset and the reason the values are missing.

Common methods include:

* Removing rows: Delete records containing missing values when appropriate.
* Removing columns: Drop columns with excessive missing data when they are not useful.
* Mean imputation: Replace missing numerical values with the mean.
* Median imputation: Replace missing numerical values with the median, especially when data contains outliers.
* Mode imputation: Replace missing categorical values with the most frequent category.
* Forward fill or backward fill: Fill missing values using nearby observations, especially in time-series data.
* Advanced imputation: Use methods such as K-Nearest Neighbours (KNN) or regression-based imputation.

In Pandas:
df.isnull().sum()  # Count missing values
df.dropna()        # Remove rows containing missing values
df.fillna(0)       # Replace missing values with 0

The method should be chosen carefully to avoid losing useful information or introducing bias.

4. What Is Data Imputation?

Data imputation is the process of replacing missing values with estimated or substituted values instead of simply removing the affected records.

Common imputation methods include:

* Mean imputation
* Median imputation
* Mode imputation
* Forward fill and backward fill
* KNN imputation
* Regression-based imputation

Example:
If the ages in a dataset are 20, 25, missing, 30, and 35, the missing value can be replaced with the mean age of 27.5.

In Pandas:
df["Age"] = df["Age"].fillna(df["Age"].median())

Note: In machine learning, calculate imputation values using the training data only, then apply them to the test data to avoid data leakage.

5. How Do You Handle Inappropriate Data?

Inappropriate data refers to data that is invalid, inconsistent, irrelevant, incorrectly formatted, or unsuitable for the intended analysis.

Common methods to handle it include:

* Remove duplicates using df.drop_duplicates().
* Correct inconsistent formats, such as different date formats.
* Fix incorrect data types using methods such as astype().
* Validate values against acceptable ranges and business rules.
* Correct spelling inconsistencies in categorical values.
* Remove irrelevant columns or records when justified.
* Investigate invalid values and correct them using reliable source information.
* Handle outliers using appropriate statistical methods when necessary.

Example:
If an Age column contains -5, 25, and 30, the value -5 is likely invalid. It should be investigated and corrected or treated as missing rather than automatically accepted.

In short: Inappropriate data should be identified, investigated, and corrected, removed, or transformed according to the context and purpose of the analysis.
